# obgit

Obsidian の vault を GitHub API 経由でファイル単位に同期するプラグイン。git も CLI も要らない。

トークンを vault の外のファイルに置くため Node の `fs` を使う。デスクトップ専用。

## できること

- 双方向同期（ボタン / コマンド `GitHub と同期`）
- 差分判定は git の blob SHA。前回同期時の SHA を基準に pull / push / 削除を決める
- 両方で更新されたファイルは競合として `_conflict/` にリモート版を書き出し、ローカルはそのまま
- `.gitignore`（vault ルート）+ 設定の追加パターンで除外。`.` 始まりのパスは常に除外

## インストール

リリースの `main.js` と `manifest.json` を vault の `.obsidian/plugins/obgit/` に置いて、設定 → コミュニティプラグインで有効化。

## 設定

| 項目 | 内容 |
|---|---|
| GitHub トークン | `repo` スコープの Personal Access Token。入力欄を離れると保存先へ書き出し、欄と設定からは消える |
| トークンの保存先 | 既定 `~/.config/obgit/token`（`0600`）。vault の外 |
| リポジトリ | `owner/repo` |
| ブランチ | 既定 `main` |
| 端末名 | コミットメッセージの接頭辞 |
| 追加の除外パターン | `.gitignore` に加えて除外するパターン |

## トークンの扱い

vault 内の `data.json` に残るのは**保存先のパスと SHA-256 だけ**で、トークン本体は入らない。同期のたびに保存先のファイルを読み、ハッシュが設定時と一致したときだけ使う。

- ファイルが無い / 読めない → 同期せずポップアップで警告
- 内容が設定時と違う（すり替え・編集ミス）→ 同期せずポップアップで警告

vault を同期・共有してもトークンは渡らない。保存先のファイル自体は平文なので、ディスク暗号化やファイルのパーミッションで守ること。以前のバージョンで `data.json` に平文保存されていたトークンは、起動時に保存先へ移して `data.json` からは消える（**Git 履歴やバックアップに残っている分は自分で失効させること**）。
